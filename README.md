# sangmyung_wiki

## 배경
상명대학교 홈페이지 내 학사정보를 탐색하기 위해서는 정확한 키워드와 수많은 페이지를 통해야 정보에 접근할 수 있어 학생들의 불편이 있습니다. 또한 학교내 시설(카페, 학생식당, 스터디룸 등)에 대한 정보, 학교 주변 상권에 대한 정보 등을 직접 알아보거나 특정 커뮤니티에 질문을 통해 알아보는 것 외에는 정보를 얻을 수 없어 이를 보완하고 해결하고자 학사 정보 및 학교생활관련 정보를 통합하여 제공할 수 있는 웹서비스를 개발하였습니다.
